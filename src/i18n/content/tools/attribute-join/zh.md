## 这个工具解决什么问题

矢量文件通常只有几何和几个字段，人口、面积、行政区代码、分类名称这些信息，却往往单独躺在 CSV 或 Excel 里。要把两边并起来，桌面 GIS 叫「按字段连接属性表」，数据库是一条 JOIN，Excel 里则是 VLOOKUP。

这里的流程就四步：选主矢量文件、选属性表、各挑一个连接字段、点连接。匹配上的要素在地图上显示，属性表的列全部并入要素属性，结果可以导出 GeoJSON，接着拿去做预览、裁切、按属性提取或按字段融合。

典型场景：给地块补上用地分类；给 POI 补上行政区与人口；把测量点与台账按编号对上；把 Excel 里的统计值挂到地图单元上做专题图。

## 怎么用

先选主矢量文件。支持的格式与格式转换工具相同：GeoJSON、TopoJSON、KML / KMZ、GPX、CSV / TSV、Excel、Shapefile（zip 包）、FlatGeobuf、GeoPackage、WKT、GML、DXF、MIF / MID 与 GMT。GeoPackage 与 Shapefile ZIP 会列出文件内的真实图层；GeoJSON 没有原生图层，按几何类型拆成点、线、面、其他几个逻辑图层。分组超过两个时，文件卡片下会出现图层下拉框。

再选属性表文件。普通二维表即可：第一行是表头，之后一行一条记录，支持 CSV、TSV、Excel（首个工作表）。它不需要经纬度列，也不会被当成点位数据。

第三步选两个连接字段，左边来自矢量要素，右边来自属性表的列。两个下拉框显示的都是实际字段名，属性表卡片还会给出行数与列数，方便确认读对了表。

最后决定要不要勾「保留未匹配要素」。勾上，属性表里找不到对应行的要素仍留在结果里，几何与原有属性都不动；不勾，这些要素会被剔除。点连接之后，结果卡片给出已匹配、未匹配与字段冲突三项统计，重复键的数量单独提示。

地图上绿色的是连接结果，蓝色是原始矢量。点开要素能看到它的全部属性，用来确认属性表的值确实挂上了。

## 类型与结果

- 匹配键先转成字符串，再去掉首尾空格。数值 1 和文本 "1" 视为同一个；布尔值按 true / false 比较；缺失、null 与空串不参与匹配，免得一堆空值被连成一行。
- 属性表出现重复键，只采用第一次出现的那行，其余计入「重复键」提示，同一个要素不会被覆盖多次。
- 属性表的列名与矢量字段同名时，用属性表的值覆盖原值。被覆盖的要素数记入「字段冲突」，两个连接字段本身不算冲突。
- 结果保留原始几何、要素顺序与全部属性，导出为 GeoJSON。顺序跟着源矢量走，不会因为属性表的顺序而重排。
- 属性表里的数字在 CSV / Excel 读进来后是文本；本工具不做数值转写，导出的属性值与表格里看到的写法一致。

## 限制与精度

- 矢量文件单次最多 20 MB、50,000 个要素。更大的数据请先裁剪范围或简化几何。
- 只做「一个字段对一列」的等值连接，范围连接、模糊匹配、多字段联合键都不支持。要多字段，先在表格里拼一个辅助列。
- 属性表按 UTF-8 读取，暂时没有编码切换。中文列名或内容出现乱码时，先在表格软件里另存为 UTF-8 编码的 CSV。
- 只处理属性，不改坐标。数据不是 WGS84 经纬度的话，地图位置会偏移，请先用 EPSG 转换工具处理。
- 所有计算在浏览器本地完成，文件不会上传，也不会写入服务器日志。

## 常见问题

**为什么一个都没匹配上？** 先看两个连接字段是不是选反了，再核对值的写法。数字 1 与文本 "1" 能对上，但 "01" 与 "1"、带空格和不带空格的编号不会自动归一。可以先把两列都导出，看看实际值。

**属性表有重复编号怎么办？** 只取第一次出现的那行，结果卡片会提示重复数量。要保留全部记录，先在表格里合并重复项，或者改成每个键只出现一次。

**能连接 Excel 的多个工作表吗？** 目前只读第一个工作表。把需要连接的那张表放到最前面，或者单独另存为 CSV。

**连接后能继续做空间分析吗？** 能。导出的 GeoJSON 可以直接作为裁切、缓冲区、按属性提取与按字段融合的输入。
