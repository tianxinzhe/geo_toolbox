## 这个工具解决什么问题

矢量文件通常只有几何和少量字段，而人口、面积、行政区代码、分类名称这些信息往往单独存放在 CSV 或 Excel 里。要把两者合到一起，桌面 GIS 里叫「按字段连接属性表」，数据库里是一条 JOIN，Excel 里是 VLOOKUP。

本工具把这一步做成四件事：选主矢量文件、选属性表、各选一个连接字段、点连接。匹配成功的要素会在地图上显示，属性表的所有列被并入要素属性，结果可以导出为 GeoJSON，继续用于预览、裁切、按属性提取或按字段融合。

典型场景包括：给地块补上用地分类；给 POI 补上行政区与人口；把测量点与台账表按编号对上；把 Excel 里的统计值挂到地图单元上做专题图。

## 怎么用

第一步，选择主矢量文件。支持与格式转换工具相同的格式：GeoJSON、TopoJSON、KML / KMZ、GPX、CSV / TSV、Excel、Shapefile（zip 包）、FlatGeobuf、GeoPackage、WKT、GML、DXF、MIF / MID 与 GMT。GeoPackage 与 Shapefile ZIP 会列出文件内的真实图层；GeoJSON 没有原生图层，会按几何类型拆成点、线、面、其他几个逻辑图层。出现两个以上分组时，文件卡片下会出现图层下拉框。

第二步，选择属性表文件。属性表只需要是普通的二维表：第一行是表头，之后每行一条记录，支持 CSV、TSV、Excel（首个工作表）。它不需要经纬度列，也不会被当成点位数据。

第三步，选择两个连接字段。左边是矢量要素上的字段，右边是属性表的列。两个下拉框都会显示实际字段名，属性表文件卡片还会显示行数与列数，方便确认读对了表。

第四步，决定是否勾选「保留未匹配要素」。勾选时，在属性表里找不到对应行的要素仍然保留，几何与原有属性不变；取消勾选时这些要素会被剔除。点击连接后，结果卡片显示已匹配、未匹配与字段冲突三项统计，重复键的数量会单独提示。

地图上的绿色要素是连接后的结果，蓝色是原始矢量。点击要素可以查看它的全部属性，确认属性表的值确实挂上去了。

## 类型与结果

- 匹配键会先做字符串化并去掉首尾空格。数值 1 与文本 "1" 视为相同；布尔值按 true / false 比较；缺失、null 与空串不参与匹配，避免所有空值被连成一行。
- 属性表若有重复键，只采用首次出现的那一行，其余行计入「重复键」提示，不会把同一要素覆盖多次。
- 属性表列名与矢量字段同名时，属性表的值覆盖原值。覆盖涉及的要素数计入「字段冲突」，两个连接字段本身不算冲突。
- 结果保留原始几何、要素顺序与全部属性，导出为 GeoJSON。要素顺序与源矢量一致，不会因为属性表顺序而重排。
- 属性表里的数字在 CSV / Excel 读入后是文本；本工具不做数值转写，导出的属性值与表格中看到的写法一致。

## 限制与精度

- 一次最多处理 20 MB、50,000 个要素的矢量文件。更大的数据请先裁剪范围或简化几何。
- 只做「一个字段对一列」的等值连接，不支持范围连接、模糊匹配或多字段联合键。需要多字段时，可以先在表格里拼出一个辅助列。
- 属性表按 UTF-8 读取，暂不提供编码切换；如果中文列名或内容出现乱码，请先在表格软件里另存为 UTF-8 编码的 CSV。
- 只处理属性，不改变坐标。数据若不是 WGS84 经纬度，地图位置会偏移，请先用 EPSG 转换工具处理。
- 所有计算在浏览器本地完成，文件不会上传，也不会写入服务器日志。

## 常见问题

**为什么一个都没匹配上？** 先看两个连接字段是否选反，再检查值的写法。数字 1 与文本 "1" 可以匹配，但 "01" 与 "1"、带空格的编号与不带空格的编号不会自动归一。可以先把两列都导出看看实际值。

**属性表有重复编号怎么办？** 本工具只取首次出现的那一行，并在结果卡片提示重复数量。若需要保留全部记录，请先在表格里合并重复项，或把属性表改成每个键只出现一次。

**能连接 Excel 的多个工作表吗？** 目前只读第一个工作表。请把需要连接的那张表放在最前面，或另存为单独的 CSV。

**连接后能继续做空间分析吗？** 可以。导出的 GeoJSON 可以直接作为裁切、缓冲区、按属性提取与按字段融合的输入。
