## 这个工具解决什么问题

一份地块、POI 或道路数据里通常带属性表：用地类型、行政区名称、人口、面积、状态……想只看其中一类，在桌面 GIS 里是「按属性提取」，在数据库里是一条 WHERE 条件。本工具把这一步做成选字段、选条件、填值三件事，符合条件的要素直接在地图上高亮，并可以导出成新的 GeoJSON。

适合这些场景：从全市 POI 中取出某一类、筛出面积大于阈值的宗地、只保留某个行政区或某种状态的要素、检查某个字段为空的记录。

## 条件怎么选

- **等于 / 不等于**：字段是数值时按数字比较，否则按文本完全匹配。
- **包含**：文本包含，忽略大小写，适合名称、类型这类字段。
- **大于 / 大于等于 / 小于 / 小于等于**：按数值比较。字段不是数值时不会匹配任何要素，界面会提示。
- **为空 / 不为空**：不需要填值，分别匹配缺失、null、空字符串，以及其余情况。

字段下拉框会显示最多 3 个示例值，帮助确认选对了字段。条件或字段改变后，上一次的结果会自动清空，需要重新提取。

**选择现有值**：填值输入框会读取当前字段的全部不同取值（最多 200 个），按数值或文本排序后放进下拉列表，可以直接选，也可以手动输入不在列表里的值。

**多图层文件**：GeoPackage 与 Shapefile ZIP 会读取文件内的真实图层；GeoJSON 没有原生图层，按几何类型拆成点 / 线 / 面 / 其他几个逻辑图层。出现两个以上分组时，文件卡片下会显示「图层」下拉框；切到「全部要素」则不做拆分。切换图层会刷新字段、条件与结果。

## 类型与结果

- CSV、Excel 导入的属性值本质上是字符串；本工具会在比较前判断整列是否都是数字，再决定按数字还是文本比较，避免字典序把 "9" 判成大于 "10"。
- 结果保留原始几何与全部属性，要素顺序与源文件一致，导出为 GeoJSON。
- 点的去重、面与线的显示由地图完成，本工具不做几何化简或修复。

## 限制与精度

- 一次最多处理 20 MB、50,000 个要素；更大的数据请先裁剪。
- 只做单条件筛选；需要 AND / OR 组合时，可以导出结果后再次提取。
- 坐标按 WGS84 经纬度解释，投影坐标会显示到错误位置，请先用 EPSG 转换工具处理。
- 所有计算在浏览器本地完成，文件不会上传，也不会写入服务器日志。

## 常见问题

**为什么命中了 0 个要素？** 先看字段是否选对（示例值能帮忙确认），再检查值是否与数据完全一致；「包含」忽略大小写，但「等于」要求文本完全相同。数值字段请确认输入的是数字而不是带单位的文本。

**能按多个字段筛选吗？** 当前一次一个条件。可以先用一个条件提取，导出 GeoJSON 后再作为输入做第二次提取。

**和裁切工具有什么区别？** 裁切按空间范围筛选，本工具按属性值筛选；两者可以串联，例如先取出某类用地，再用行政区边界裁切。
