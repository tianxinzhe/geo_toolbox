本站的[投影坐标转换](/zh/tools/epsg-convert/)支持七百多个 EPSG 坐标系，但它们并不是七百种互不相干的投影。绝大多数可以归入五类：不投影的经纬度、Web 墨卡托、UTM、高斯克吕格（含日本平面直角）和英国国土地图。

这篇按类说明：各自覆盖哪里、适合什么场景、容易在哪里出错。下面的插图给出几种主要投影方式的形状与取舍。

## 先分清三件事

一个 EPSG 代码同时锁定了三个层次：

| 层次 | 含义 | 例子 |
|---|---|---|
| 基准面（datum） | 用哪个椭球、原点在哪 | WGS84、CGCS2000、OSGB36 |
| 投影方法 | 怎么把球面摊平 | 墨卡托、横轴墨卡托 |
| 单位与参数 | 米还是度、中央经线、假东 | 3° 带 117°E、500 km |

所以 `EPSG:4548` 与 `EPSG:32650` 都用横轴墨卡托，但基准面和分带方式不同，坐标不能直接混用。

## 不投影的经纬度

`EPSG:4326`、`EPSG:4490` 这类坐标的单位是度，不是米。它们适合当「存储和交换的标准」：任何软件都认，任何接口都能传。缺点是角度不能直接量距离和面积——一度经度在赤道约 111 km，在北京只有约 85 km。

日常看到的大多数坐标都属于这一类。需要量测时，再临时投影。

## Web 墨卡托（EPSG:3857）

几乎所有网页地图（Leaflet、Mapbox、Google Maps 等）的瓦片都用它。它把地球切成正方形瓦片，方便按层级加载。

![圆柱投影示意：球心一点发出射线，把地表投到相切的圆柱面](/images/projections/mercator-cylinder.png)

*圆柱投影的构造：球心一点向四周发出射线，落到与赤道相切的圆柱面上，再把圆柱展开成平面，经线成为等距的竖线、纬线成为水平线。墨卡托在这个框架上再按纬度做南北向拉伸，才得到等角的结果。图：Wikimedia Commons，[Projectieprincipe.PNG](https://commons.wikimedia.org/wiki/File:Projectieprincipe.PNG)*

代价是**面积严重失真**：纬度 60° 处面积放大约 4 倍，格陵兰看起来和非洲差不多大。所以它适合展示，不适合量面积或量长距离。

![墨卡托投影世界地图，格陵兰与南极洲被明显放大](/images/projections/mercator.jpg)

*墨卡托投影：经纬线互相垂直，局部形状保持不变，但高纬度面积被放大。Web 墨卡托沿用同样的形状。图：Strebe，CC BY-SA 3.0，[Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Mercator_projection_SW.jpg)*

## UTM

UTM 是横轴墨卡托的全球分带版本：每 6° 一经带，共 60 带；中央经线比例因子 0.9996，假东 500 km。

- `EPSG:326xx` 北半球、`327xx` 南半球，`xx` 是带号。
- 中国大部分地区落在 43~53 带，例如北京在 50 带，即 `EPSG:32650`。
- 日本使用 JGD2011 的 51~55 带（`EPSG:6688~6692`）。

![UTM 分带世界地图，每 6° 一带并标注带号](/images/projections/utm-zones.jpg)

*UTM 把全球分成 60 个 6° 经带，每带独立投影、独立带号。图：公有领域（美国政府作品），[Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Utm-zones.jpg)*

优点是带号全球统一，跨国数据好拼接；缺点是带边缘变形略大，正好落在带边界上的工程要先评估跨带问题。

## 高斯克吕格

中国工程最常用。它与 UTM 同为横轴墨卡托，但有两个关键差别：

- **分带更窄**：以 3° 带为主，6° 带用于小比例尺。
- **中央经线比例因子为 1**，中央经线上没有尺度缩小。

本站覆盖三个基准面 × 两种带宽：

| 基准面 | 3° 带 EPSG | 6° 带 EPSG |
|---|---|---|
| CGCS2000 | `4534~4554` | `4502~4512` |
| 西安 1980 | `2370~2390` | `2338~2348` |
| 北京 1954 | `2422~2442` | `21453~21463` |

中央经线从 75°E 到 135°E。选带时要确认数据的中央经线，而不是只看「3 度带」三个字。

## 日本平面直角坐标系

日本测量与登记使用 19 个区带，每带一个原点，比例因子 0.9999，假东与假北都是 0。

| 基准面 | 第 I~XIX 系 EPSG |
|---|---|
| JGD2011 | `6669~6687` |
| JGD2000 | `2443~2461` |
| Tokyo | `30161~30179` |

它有一个特殊之处：**轴序是 X=北、Y=东**，与常见的 X=东、Y=北相反。本站转换页面会按坐标系显示「北方向 (X) / 东方向 (Y)」，避免填反。

## 英国国土地图（EPSG:27700）

英国地形测量局使用的横轴墨卡托投影，基准面 OSGB36，单位米。英国地形、地址与规划数据常见这个代码。它与 ETRS89 / WGS84 之间有米级偏移，不能直接当经纬度处理。

## 其他常见投影方式

下面四种没有放进本站的常用列表，但读地图和选投影时会遇到。

### 兰勃特等角圆锥（Lambert conformal conic）

用一个圆锥套在中纬度地区，经线是放射状直线，纬线是同心圆弧。它等角，适合东西向延伸的中纬度区域，航空图与国家基本图常用。

![兰勃特等角圆锥投影世界地图，纬线呈同心圆弧](/images/projections/lambert-conformal-conic.jpg)

*图：Strebe，CC BY-SA 3.0，[Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Lambert_conformal_conic_projection_SW.jpg)*

### 阿尔伯斯等积圆锥（Albers equal-area conic）

同样用圆锥，但优先保住面积。国家尺度的土地利用、人口密度、农业统计常用它，因为不同省份的面积可以直接比较。

![阿尔伯斯等积圆锥投影世界地图](/images/projections/albers.jpg)

*图：Strebe，CC BY-SA 3.0，[Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Albers_projection_SW.jpg)*

### 方位等距投影（Azimuthal equidistant）

从一个中心点向四周投影，到中心的距离准确。极区地图、航空与无线电覆盖图常用；以某座城市为中心时，可以直观看出各方向的等距范围。

![以北极为中心的方位等距投影世界地图](/images/projections/azimuthal-equidistant.jpg)

*图：Strebe，CC BY-SA 3.0，[Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Azimuthal_equidistant_projection_SW.jpg)*

### 罗宾逊（Robinson）

一种折中投影：既不保角也不保积，而是让面积与形状的误差都比较温和。世界专题图与教科书里的全球示意图常用它。

![罗宾逊投影世界地图，呈椭圆外形](/images/projections/robinson.jpg)

*图：Strebe，CC BY-SA 3.0，[Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Robinson_projection_SW.jpg)*

选这些投影时，原则仍然是先确定要保住什么：角度、面积，还是到某一点的距离。

## 同一投影，不同基准

同一套投影参数下，基准面不同，坐标会差几十米到几百米：

- **CGCS2000 与 WGS84**：实用精度内差厘米级，可近似互换。
- **西安 1980**：缺少官方七参数，本站不会静默当成 WGS84，需要你提供转换参数。
- **北京 1954**：使用 Krassovsky 椭球，与 WGS84 差百米级。
- **Tokyo（Bessel 椭球）**：与 JGD2011 差数百米；2011 年地震后日本全面转向 JGD2011。
- **JGD2000 与 JGD2011**：东日本大地震导致基准偏移，在东日本两者差数十厘米。

这也是为什么「转换结果差了几十米」时，要先查基准面，再查投影参数。

## 场景速查

| 你要做什么 | 选什么 |
|---|---|
| 存数据、传给别的系统 | `EPSG:4326` 或对应国家的经纬度代码 |
| 做网页地图 | `EPSG:3857` |
| 中国境内量距离、算面积、出图 | CGCS2000 3° 带，按中央经线选 |
| 跨国或跨洲工程 | UTM，按经度选带 |
| 日本测量、登记、施工 | JGD2011 平面直角，按都道府县选区带 |
| 英国地址与规划 | `EPSG:27700` |
| 只是看一眼点在哪 | 任意，但别用它算数 |

## 三个注意事项

1. **带号与中央经线要一起确认**。只写「3 度带」不够，还要说明带号或中央经线。
2. **跨带不要硬转**。数据横跨两带时，边缘变形会明显增大，应分带处理或改用覆盖更大的投影。
3. **轴序与单位跟着坐标系走**。日本平面直角是 X=北；投影坐标单位是米，经纬度单位是度。
